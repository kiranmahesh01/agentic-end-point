Agentic Endpoint Security

Independent Execution Broker for AI Agents

The agent proposes. The broker decides.

The Problem

Agents on endpoints misuse legitimate tools and valid credentials.

The exploit is often a sentence—not malware.

Goal Hijacking

A prompt injection causes the agent to work for the attacker using the user's tools.

Poisoned Skill

A malicious tool definition loaded from a repository executes attacker code.

Inherited Token

The agent inherits the user's PAT and exfiltrates it via legitimate APIs.

Why Now?

  • Coding agents in every IDE writing and executing code
  • Browser extensions with full page access and API credentials
  • MCP servers exposing tools and resources locally
  • Skills and plugins extending agent capabilities
  • Local models processing sensitive enterprise data

All acting as the user. All inheriting credentials. All potential attack surfaces.

Why EDR Is Not Enough

EDR stays mandatory. EDR sees the user's process. EDR cannot see:

Agent Identity

Which specific agent performed this action?

Declared Goal

What was the agent trying to accomplish?

Input Trust

Was the input from a trusted or untrusted source?

Tool Integrity

Has the skill definition been modified?

Scope Boundaries

Is this action within the agent's approved permissions?

Task Context

What task is this action part of?

Architecture Thesis

The agent PROPOSES actions.

An independent PEP DECIDES.

Model classifier is an advisor, not a boundary.

How an Action Is Mediated

  1. Agent calls broker.read_file("/workspace/data.txt")
  2. Broker canonicalizes path, rejects traversal
  3. Broker sends ActionRequest to PDP
  4. PDP queries Registry: known? active? approved?
  5. PDP checks permissions: can this agent read here?
  6. PDP checks input trust: was input trusted?
  7. PDP returns: ALLOW / DENY / REQUIRE_APPROVAL
  8. Broker executes or returns error
  9. Telemetry records decision

Data Safety

No Raw User PAT

5-minute scoped tokens. Never relay user credentials.

Default-Deny Egress

Network access requires explicit allowlist entry.

No Raw Shell

Typed commands only. Never a shell string endpoint.

Approved Roots Only

Writes only to approved paths. Path traversal rejected.

permissions:
files_write: ["/approved/output"]
network_allowlist: ["reports.internal.example"]
shell: false # Always

Kill Switch

Not a polite stop. A hard kill. Does not ask the agent nicely.

  1. Suspend component in registry (new actions fail immediately)
  2. Revoke all tokens for agent
  3. Terminate task tree in broker
  4. Hook EDR isolate
  5. Hook egress deny

Order matters. Registry first, so new actions fail before tokens are revoked.

Integrate
